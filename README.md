# 《明天的回忆》本地官网

## 预览

直接双击 `index.html` 即可浏览。若浏览器限制本地脚本，可在此目录打开 PowerShell 后运行：

```powershell
python -m http.server 8018
```

然后访问 `http://localhost:8018`。

## 文件结构

- `index.html`：页面内容与结构
- `styles.css`：橙色纸张质感、版式与动效`r`n- `company.css`：SHADOW 公司章节与响应式布局
- `app.js`：滚动显影、鼠标光晕和分镜弹窗
- `assets/`：网页使用的影片视觉资产副本

网页中的资产均为副本，修改网页不会影响原始视觉资产。
